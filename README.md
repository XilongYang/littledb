# LittleDB

LittleDB is an educational key–value storage engine implemented in pure C.

The project explores the architecture of LSM-tree based storage systems,
including components such as write-ahead logging, memtables, SSTables,
compaction, and crash recovery.

LittleDB is not intended to be a production database. Instead, it serves as a
learning-oriented implementation for studying storage engine design and system
architecture.
